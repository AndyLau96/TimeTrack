After processing, the tool creates a new Excel file containing two worksheets:

Sheet 1 – Overview

This sheet provides a summary of each employee's attendance, including:

Total working hours
Number of late arrivals
Number of early departures
Sheet 2 – Details

This sheet contains the detailed attendance records for each employee on each working day.

==========================================================================================================================================================================
							How to Use
==========================================================================================================================================================================

* Step 1: Configure the Rules

Before processing your attendance file, you need to configure the calculation rules.

Click the Rules button. You will see four settings:

Work Start – Employee starting time
Work End – Employee ending time
Lunch Time – Lunch break duration
Required Time – Minimum required working hours per day
Default Values

If you do not change these settings, the tool will use the following default values:

Setting	Default Value
Work Start	08:00 AM
Work End	05:00 PM
Lunch Time	1 hour
Required Time	8 hours
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------

* Step 2: Select the Attendance File

Click Select Path and choose the Excel attendance file that you want the tool to calculate.
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------

* Step 3: Choose the Output Location

Click Save As and select the location where the generated Excel report will be saved.
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------

* Step 4: Start the Calculation

After completing all the settings, click Confirm.

The tool will automatically:

Read the attendance data from your Excel file.
Calculate each employee's working hours.
Generate a new Excel report with two worksheets (Overview and Details).
Highlight employees who arrived late or left early, making them easy to identify.
